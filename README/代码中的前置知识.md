## 一、李群与李代数

### 1. 群、流形与李群

#### 群 (Group)

群是一个集合 $G$ 配上一种二元运算 $\circ: G \times G \to G$，满足四条公理：

| 公理 | 含义 | 数学表述 |
|------|------|---------|
| **封闭性** | 两个群元运算结果仍在群中 | $\forall a,b \in G,\ a \circ b \in G$ |
| **结合律** | 运算顺序不影响结果 | $(a \circ b) \circ c = a \circ (b \circ c)$ |
| **单位元** | 存在"不变"的元素 | $\exists e \in G,\ \forall a: e \circ a = a \circ e = a$ |
| **逆元** | 每个元素都能"撤销" | $\forall a \in G,\ \exists a^{-1}: a \circ a^{-1} = e$ |

**例子**：
- 整数加法群 $(\mathbb{Z}, +)$：单位元 0，逆元为相反数
- 可逆矩阵乘法群 $GL(n)$：单位元 $I$，逆元为矩阵的逆

#### 流形 (Manifold)

流形是**局部上同胚于欧氏空间**的拓扑空间。通俗地说：

> 流形是"弯曲的空间"，但在每个点附近看起来像平坦的欧氏空间 $\mathbb{R}^n$。

**例子**：
- 球面 $S^2$：地球表面是二维流形，在局部地图上看是平的
- $\mathbb{R}^n$ 本身是一个平凡流形

#### 李群 (Lie Group)

**李群 = 群 + 光滑流形**，即同时具有群结构和光滑流形结构的数学对象。

**直观理解**：
- 作为**群**，李群的元素可以"相乘"和"求逆"
- 作为**光滑流形**，李群的元素可以"连续变化"（可微）

**机器人学中最重要的李群**：

| 李群 | 名称 | 描述的对象 |
|------|------|-----------|
| $SO(3)$ | 三维特殊正交群 | 刚体的旋转/朝向 |
| $SE(3)$ | 三维特殊欧氏群 | 刚体的位姿（位置+朝向） |
| $S^1$ | 圆群 | 平面旋转角 |

### 2. 李代数 (Lie Algebra)

#### 核心思想

李代数是**李群在单位元处的切空间**，描述了李群上的"无穷小运动"。

```
                  切空间（李代数）
                 ↑
    ·            |            ·
     \           |           /
      \          |          /
       \         |         /
        \        |        /
         \       |       /
          ·——————→——————·——————→
         g        e       g'
                  ↑
                单位元
```

#### 数学定义

李代数是一个向量空间 $\mathfrak{g}$，配上一个二元运算 $[\cdot, \cdot]: \mathfrak{g} \times \mathfrak{g} \to \mathfrak{g}$（称为**李括号**），满足：

1. **双线性**：对两个参数都是线性的
2. **反对称性**：$[X, Y] = -[Y, X]$
3. **Jacobi 恒等式**：$[X, [Y, Z]] + [Y, [Z, X]] + [Z, [X, Y]] = 0$

#### 机器人学中的李代数

| 李群 | 对应的李代数 | 物理含义 |
|------|------------|---------|
| $SO(3)$ | $\mathfrak{so}(3)$ | 角速度 |
| $SE(3)$ | $\mathfrak{se}(3)$ | 刚体速度（twist） |

#### hat 映射 ($\wedge$) 与 vee 映射 ($\vee$)

这两个映射是李代数与向量表示之间的桥梁。

**hat 映射 ($\hat{\cdot}$)**：将向量 $\to$ 反对称矩阵

```math
\hat{\omega} =
\begin{bmatrix}
0 & -\omega_3 & \omega_2 \\
\omega_3 & 0 & -\omega_1 \\
-\omega_2 & \omega_1 & 0
\end{bmatrix},
\quad
\omega = \begin{bmatrix}\omega_1 \\ \omega_2 \\ \omega_3\end{bmatrix} \in \mathbb{R}^3
```

**vee 映射 ($\vee$)**：反对称矩阵 $\to$ 向量（hat 的逆）

```math
\begin{bmatrix}
0 & -c & b \\
c & 0 & -a \\
-b & a & 0
\end{bmatrix}^\vee =
\begin{bmatrix}a \\ b \\ c\end{bmatrix}
```

**代码中对应的函数**：
- `hat_map(w)` — `gufic_env/utils/misc_func.py` 中的实现
- `vee_map(M)` — 同上

#### 指数映射 (Exponential Map)

指数映射 $\exp: \mathfrak{g} \to G$ 将李代数（切空间）中的元素映射到李群（流形）上。

**物理意义**：将角速度/速度"积分"为旋转/位姿。

对于 $SO(3)$：

```math
\exp(\hat{\omega}\theta) = I + \hat{\omega}\sin\theta + \hat{\omega}^2(1-\cos\theta)
```

这就是 **Rodrigues 公式**。

对于 $SE(3)$（代码中用到的）：

```math
\exp\left(
\begin{bmatrix}
\hat{\omega} & v \\
0 & 0
\end{bmatrix}
\right) =
\begin{bmatrix}
R & p \\
0 & 1
\end{bmatrix}
```

**代码中使用**：
```python
from scipy.linalg import expm
self.gd = gd @ expm(Vd_mod_hat * self.dt)
```
这里的 `expm(Vd_mod_hat * dt)` 将体速度 $\times$ 时间步长积分，得到 SE(3) 上的增量位姿。

### 3. SE(3) 及其如何描述空间运动

#### SE(3) 的定义

**SE(3)** = Special Euclidean Group (三维特殊欧氏群):

```math
SE(3) = \left\{
g = \begin{bmatrix}
R & p \\
0 & 1
\end{bmatrix}
\ \Bigg|\
R \in SO(3),\ p \in \mathbb{R}^3
\right\}
```

这是一个 $4 \times 4$ 的齐次变换矩阵：

- $R$ ($3 \times 3$)：描述末端朝向（旋转）
- $p$ ($3 \times 1$)：描述末端位置（平移）
- 最后一行固定为 $[0, 0, 0, 1]$

#### 代码中的 SE(3) 表示

**位姿 (Pose)**：

```python
# 当前末端位姿 g ∈ SE(3)
g = np.eye(4)
g[:3, :3] = R    # SO(3) 旋转矩阵
g[:3, 3] = p     # ℝ³ 位置向量
```

**期望位姿 gd**：

```python
gd = np.eye(4)
gd[:3, :3] = Rd   # 期望朝向
gd[:3, 3] = pd    # 期望位置
```

#### SE(3) 上的伴随变换 (Adjoint Transformation)

当需要在不同坐标系之间变换速度量（twist）时，使用伴随变换：

```math
Ad(g) = \begin{bmatrix}
R & \hat{p}R \\
0 & R
\end{bmatrix} \in \mathbb{R}^{6 \times 6}
```

**物理意义**：将体速度从一个坐标系"拉"到另一个坐标系。

**代码中的使用**：
```python
# GIC: 将期望速度从 gd 的体坐标系变换到当前 g 的体坐标系
Vd_star = adjoint_g_ed(g_ed) @ Vd
```

```python
# GUFIC: 将修正后的期望速度变换回世界系用于积分
Vd_mod = adjoint_g_ed(np.linalg.inv(g_ed)) @ Vd_star_mod
```

#### SE(3) 上的误差

在 SE(3) 上定义"位置误差"和"朝向误差"：

```python
# 位置误差（体坐标系中表达）
ep = R.T @ (p - pd)

# 朝向误差（so(3) 中表达）
eR = vee_map(Rd.T @ R - R.T @ Rd)
```

**为什么这样定义？**
- 传统欧拉角有万向锁问题，且不唯一
- SE(3) 上的几何误差是**全局**的，无奇异点
- 物理意义清晰：ep 是体坐标系中的位置偏差，eR 是 so(3) 中的朝向偏差

#### 体速度 (Body Twist)

末端执行器的速度用 **体速度 (body twist)** $V_b \in \mathfrak{se}(3)$ 表示：

```math
V_b = \begin{bmatrix} v \\ w \end{bmatrix} \in \mathbb{R}^6
```

- $v$：**体坐标系**下的线速度（在机器人本体坐标系中表达）
- $w$：**体坐标系**下的角速度

**代码中的获取**：
```python
Vb = self.robot_state.get_body_ee_velocity()  # shape: (6,1)
```

**体速度 vs 世界系速度**：
- 体速度：在机器人末端自身坐标系中测量，不随旋转变化
- 世界系速度：在世界惯性系中测量，随旋转变化
- 控制律中使用体速度更方便，因为传感器（IMU、力传感器）通常固连在末端

#### DOF（自由度）的几何意义

```
刚体在 3D 空间中的自由度 = 6
├── 平移自由度 = 3  (x, y, z 方向)
└── 旋转自由度 = 3  (roll, pitch, yaw)

SE(3) 的维度 = 6
SO(3) 的维度 = 3
𝔰𝔢(3) 的维度 = 6
𝔰𝔬(3) 的维度 = 3
```

## 二、能量油箱机制 (Energy Tank)

### 为什么需要能量油箱？

在力-阻抗统一控制中：

- **阻抗控制**起"弹簧-阻尼"作用，是被动的、耗能的
- **力控制**是主动的，可能向系统注入能量
- 如果力控制注入过多能量，系统可能变得不稳定

**能量油箱**的作用就是：**限制主动力控制注入的能量，保证系统整体无源性 (passivity)**。

### 核心原理

能量油箱是一个虚拟的"能量容器"：

```math
T = \frac{1}{2} x^2
```

- $T$：油箱当前储存的能量
- $x$：油箱状态变量（类似"势能"的平方根）

### 两套油箱系统

代码中实现了**两个独立的能量油箱**：

#### 油箱 1：力控制油箱 (Force Tank)

| 变量 | 含义 |
|------|------|
| `x_tf` | 力油箱的状态变量 |
| `T_f = 0.5 * x_tf²` | 力油箱的当前能量 |
| `inner_product_f = Vbᵀ · F_f` | 力控制注入的功率 |
| `gamma_f` | 能量回收标志（功率为负时=1，回收能量） |
| `alpha_f` | 能量释放系数（能量充足时=1，不足时<1） |

**工作流程**：

```
力控制器输出 F_f
    ↓
计算功率 inner_product_f = Vbᵀ · F_f
    ↓
if 功率 < 0 (gamma_f=1):
    力控制在做负功 → 能量回收到油箱
if 油箱能量 T_f > 阈值 (alpha_f=1):
    可以释放能量 → 力控制全功率工作
if 油箱能量 T_f < 低阈值 (alpha_f=0):
    能量不足 → 抑制力控制
    ↓
F_f_mod = activation_force * F_f  (经过缩放)
```

#### 油箱 2：阻抗油箱 (Impedance Tank)

| 变量 | 含义 |
|------|------|
| `x_ti` | 阻抗油箱的状态变量 |
| `T_i = 0.5 * x_ti²` | 阻抗油箱的当前能量 |
| `inner_product_i` | 阻抗控制注入的功率 |
| `gamma_i` | 能量回收标志 |
| `alpha_i` | 能量释放系数 |

**特殊之处**：阻抗油箱还考虑了**能量耗散**项 `energy_dissipation`：

```python
energy_dissipation = ev_mod.T @ Kd @ ev_mod
```

这部分是阻抗控制中的阻尼耗散的能量，也被回收到油箱中。

### 代码流程

```python
# 1. 功率计算
inner_product_f = (Vb.T @ F_f).reshape((-1,))[0]

# 2. 判断能量流方向
gamma_f = 1 if inner_product_f < 0 else 0  # 负功率 → 能量回收

# 3. 判断油箱能量水平
beta_f = 1 if T_f <= T_f_high else 0       # 油箱未满
alpha_f = ...                               # 根据 T_f 计算释放系数

# 4. 油箱状态更新
dx_tf = - (beta_f/x_tf) * gamma_f * inner_product_f + (alpha_f/x_tf) * (gamma_f-1) * inner_product_f
x_tf += dx_tf * dt

# 5. 控制输出缩放
activation = gamma_f + alpha_f * (1 - gamma_f)
F_f_mod = activation * F_f
```

### 直观类比

```
能量油箱就像一个"水库"：
├── 当力控制做正功（向系统注入能量）= 从水库放水
├── 当力控制做负功（被系统拉着走）= 雨水回流水库
├── 水库没水了 (T_f < T_f_low) → 停止放水
└── 水库满了 (T_f > T_f_high) → 停止回收
```

## 三、论文的总体思路

### 核心问题

**传统力-阻抗控制的问题**：
1. 使用欧拉角表达朝向 → 万向锁、非唯一性
2. 力控制和阻抗控制独立设计 → 推拉冲突
3. 稳定性难以保证 → 缺乏无源性分析

### 论文的解决方案

在 **SE(3) 上设计几何统一的力-阻抗控制框架**：

```
┌─────────────────────────────────────────────────────────┐
│                 GUFIC 控制框架                          │
│                                                         │
│  期望轨迹 ──→ 速度场(Velocity Field)                    │
│                    ↓                                    │
│                Vd_star (期望体速度)                     │
│                    ↓                                    │
│   ┌────────────────┴────────────────┐                  │
│   │              ┌──────┐           │                  │
│   │  阻抗控制 ←──│ 油箱 ├──→ 力控制  │                  │
│   │   (位置+朝向) └──────┘  (PI+整形) │                  │
│   └────────────────┬────────────────┘                  │
│                    ↓                                    │
│   τ_cmd = Jᵀ(前馈 - 阻尼 - 弹簧 + 力控) + 偏置补偿    │
│                    ↓                                    │
│                MuJoCo 仿真                              │
└─────────────────────────────────────────────────────────┘
```

### 关键技术

#### 1. SE(3) 上几何构造速度场

$$
V_d^* = \begin{bmatrix}
R^T \dot{R}_d R_d^T (p - p_d) + R^T \dot{p}_d - \zeta R^T (p - p_d) \\
\text{vee}\big(R^T \dot{R}_d R_d^T R - \zeta(R_d^T R - R^T R_d)\big)
\end{bmatrix}
$$

- 位置误差和朝向误差**同时指数收敛**
- 收敛速度由 $\zeta$ 控制
- 天然避免了欧拉角的问题

#### 2. 力-阻抗协调

通过**整形函数 (shaping function)** $\rho$ 协调力控制和阻抗控制：

```python
if ep @ f_d <= 0:       # 误差和力方向相反 → 不冲突
    rho = 1
elif ep @ f_d > 0:      # 方向相同 → 可能存在冲突
    rho = 0.5*(1+cos(π*ep/d_max))  # 平滑衰减
    ...
```

**物理意义**：如果力方向和位置误差方向"对着干"，说明力控制会增大误差，此时减弱力控制作用，让阻抗控制主导。

#### 3. 无源性保证

能量油箱确保了力控制不会破坏系统的**无源性 (passivity)**，从而保证了接触环境后的稳定性。

#### 4. 控制律完整结构

$$
\tau = J^T \big( \tilde{M} \dot{V}_d^* - K_d e_v - f_g + F_f \big) + \tau_{\text{bias}}
$$

| 项 | 含义 | 作用 |
|----|------|------|
| $\tilde{M}\dot{V}_d^*$ | 前馈项 | 克服末端惯性 |
| $-K_d e_v$ | 速度阻尼 | 提供阻尼特性 |
| $-f_g$ | 几何弹簧力 | 提供位置+朝向刚度 |
| $+F_f$ | 力控制项 | 跟踪期望接触力 |
| $+\tau_{\text{bias}}$ | 偏置补偿 | 补偿重力和科氏力 |

### 与 GIC 的对比

| 特性 | GIC (纯阻抗) | GUFIC (统一力-阻抗) |
|------|-------------|-------------------|
| 位置跟踪 | ✅ | ✅ |
| 力跟踪 | ❌ | ✅ |
| 速度场 | ❌（用伴随变换） | ✅ |
| 能量油箱 | ❌ | ✅ |
| 力整形函数 | ❌ | ✅ |
| 适用场景 | 自由空间运动 | 接触任务（擦洗、装配） |
