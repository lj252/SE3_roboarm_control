## 1. 构建思路

### 1.1 为什么先做 GIC 被动（计划 A.9）

实验三的目的是量化"阻抗/导纳 + 刚性环境"这条经典失稳链路的稳定边界。实施顺序上，
**GIC 被动接触先做**：环境基础设施最简单、被动性验证最容易过——不加力反馈都要不发散、
稳定、可摩擦、可抬离，这是无源性验证。GAC 压入（阶段 2）留作下一步。

### 1.2 场景设计：五相位全流程

单条命令复现完整理想状态，不再是一次"撞球"：

```
逼近(approach) → 接触保持(settle) → 表面摩擦(rub) → 抬离(depart) → 保持(hold)
```

工具尖中心在球面**极坐标系**中参数化（球心在工具正下方，极角 θ 在 yz 平面扫掠，
`n(θ)=[0, sinθ, cosθ]`，θ=0 为球顶）：

| 相位 | 轨迹指令 | 目的 |
|---|---|---|
| 逼近 | 半径 r 从 r_start 匀速收缩到 r_des = R_eff − δ_pen | 沿法向逐渐逼近，接触时 v≈approach_speed |
| 接触保持 | r = r_des 静止 | 接触力建立并落入 ±10% 稳态带 |
| 表面摩擦 | r = r_des 固定，**2D 球面 Lissajous**: 极角 θ ∈ ±θ_amp 与 方位角 φ ∈ ±φ_amp 各自正弦往复且不同频 | 恒压深填充一个 **2D 接触斑块**（面积 ≫ 1D 弧线），来回摩擦不掉球 |
| 抬离 | r 回 r_start（C² 平滑步进） | 沿法向抬离，接触干净断开 |
| 保持 | 静止 | 验证无振铃、无再次误碰 |

rub 幅值用 `_bump` 平滑上升/下降（避免起止处切向加速度冲击）。

### 1.4 摩擦面积扩大（2026-08-07 更新）— 2D 球面 Lissajous

**需求**: 原表面摩擦是 1D 弧线（θ 在 ±θ_amp 往复，面积≈0）。需扩大摩擦面积并显示
球面接触点轨迹。

**方案**: 球面极坐标 `n(θ,φ)=[sinθ·sinφ, sinθ·cosφ, cosθ]`，摩擦段 θ 与 φ 各自
正弦往复且不同频（`ω_θ≠ω_φ`，默认 2×3 次）→ 在球顶切平面填充一个**扇形斑块**：
半径 `R·θ_amp`、半角 `φ_amp`，面积 ≈ `φ_amp·R²·θ_amp²`（默认 θ=0.08, φ=0.8
≈ **0.87 cm²**，约 15 mm × 21 mm，~4× 原 1D 弧线的覆盖面）。φ_amp=0 退化为原 1D 弧。

**稳定所需（关键调参，见 §3.7）**: 2D 摩擦必须配 **高带宽 ω_des=90 + 高阻尼 ζ=4**
（默认）。原 1D 配方（ω=40, ζ=2.5）在 2D 摩擦下 F_cv 会升到 ~14%（超 <10% 阈值），
需加硬切向阻抗 `K_tan=ω²M̃` 减小切向跟踪误差。

### 1.3 控制与环境接线

- **控制**: GIC 被动阻抗（`Fe_raw=None`）。`<motor>` 力矩驱动，
  阻抗律 `K_adapt=ω²M̃`、`D_adapt=2ζωM̃`（自适应操作空间惯性）。
  腕部补 `dof_armature=0.1` 电机转子惯量（修正 URDF 缺失腕部电机惯量导致的近零惯量失稳，阶段 0 结论）。
- **环境**: 复用 `verify_gac_mujoco.urdf_joints_to_mujoco_xml` 的接触环境扩展——
  `rigid_ball`（固定重质刚体球，condim=3）+ `tool_tip`（带质量工具尖，模拟 FT 传感器前的工具惯量）+
  `ee_force` 6 维力传感器。
- **轨迹跟踪**: 期望 EE 位姿 = `pd = tip_des − R0@[0,0,L]`（朝向恒为 home），
  期望体速度/加速度 `vd=Rdᵀ·v_tip`、`dvd=Rdᵀ·a_tip`，满足 GIC 的力/运动双环输入约定。
- **接触力回读**: `mj_contactForce` 累加工具尖所受接触力，再分解为法向/切向
  （法向 = 沿球心→尖径向），用于摩擦段指标。

## 3. 出现的问题以及解决方法

### 3.1 ★ 核心问题：`mj_forward` 静态接触力 ≠ `mj_step` 动态接触力

**现象**: 表面摩擦段失控——尖端只能压入 ~5 µm，力在 0–57 N 间振荡、频繁脱离。

**诊断**: 静态探针（重力关闭，`mj_forward` 运动学压入）显示接触刚度 ≈19 kN/m·pen
（与阶段 0 标定 17.84 kN/m 一致）；但**动态闭环**（`mj_step`）下近零压深等效刚度
实测 ≈**6.4 MN/m**——约束解算器隐式硬化。

**根因**: 默认 `solref=[0.02,1]` 的动态接触刚度（~6 MN/m）远超 GIC 径向阻抗刚度
`K_rad=ω²·M̃`（bw40 时 ≈9 kN/m）。控制器刚度比环境小 ~700 倍 → 力对径向微扰
超敏感 → 振荡。

**解决**: 把球 `solref` 时间常数调到 `[1.0, 1.0]`，动态接触刚度降到 ≈36 kN/m
（接近静态标定 17.8 kN/m 量级），GIC 才能在 mm 量级压深上稳定控力。
脚本新增 `--ball-solref` 参数，默认即 `[1.0,1.0]`。

> **对阶段 2（GAC）同样重要**: GAC 压入失稳边界本质就是"控制器刚度 vs 动态接触刚度"
> 之比，标定失稳临界 K_env 时必须用 `mj_step` 动态刚度这把尺子，不是 `mj_forward` 静态值。

### 3.2 陷阱：阶段 0 的"63 N 预载"是重力支撑，不是接触刚度

静态扫描强制 qpos 压入、无重力补偿，接触力含**整臂重力支撑项**（61.6 N）——
误判为"接触非线性超硬"（~63 N @ 10 µm）。用 `probe_elim.py` 关重力验证：
力掉到 ~0.18 N @ 0.01 mm（干净线性 19 kN/m）。动态 GIC 有 bias 重力补偿，无此项。

### 3.3 摩擦组合 = 几何平均（sqrt）

MuJoCo 两 geom 有效 μ = `sqrt(μ₁·μ₂)`。工具尖默认摩擦 1.0 会**破坏单设球摩擦**
的效果（0.15 vs sqrt(0.15·1.0)≈0.39）。必须同时调低两者 → 给 `tool_tip` 增加
`friction` 属性，默认 `--ball-friction 0.15 --tool-friction 0.15`（有效 μ=0.15）。

### 3.4 GIC 被动摩擦的面积受切向阻抗软度限制

切向阻抗软（K_tan≈1 kN/m at ω=40）叠加摩擦拖拽（~4.5 N / 960 N·m⁻¹ ≈ 4.6 mm
相位滞后）。摩擦面积加大 → 切向跟踪误差加大 → Fn 随径向微扰振荡（>10%）、脱离。
**解决方案不是放弃面积，而是加硬切向阻抗**——见 §3.7（高 ω_des + ζ）。

### 3.7 扩大摩擦面积的关键调参（2026-08-07 新增，对阶段 2 亦有参考）

**需求驱动**: 把 1D 弧线摩擦扩为 2D 斑块后，原默认（ω=40, ζ=2.5, cap 整圆旋转）
F_cv 直接升到 ~16%、3 ms 脱离——GIC 被动追不上大横向运动。逐项扫描后确定:

| 杠杆 | 效果 | 结论 |
|---|---|---|
| ω_des 40→90 | F_cv 明显下降（切向 K_tan=ω²M̃ 加硬，跟踪误差减小）；overshoot 略升 | **必须加硬**（默认 90） |
| ζ 2.5→4.0 | 摩擦段径向振动衰减，F_cv 再降一档 | **必须加高**（默认 4.0） |
| δ_pen 0.008→0.012 | F_cv 能到 <10% 但调节时间 >1s | 不可取（A.7 settle 超标） |
| 摩擦模式 cap（φ 整圈旋转） | 填整圆面积最大，但 F_cv 地板 ~11.5%（超阈值） | lissajous（有限 φ 扇形）更稳 |
| lissajous φ_amp ≤0.8 | F_cv <9%，overshoot 24%，settle 0.87s，全过 | **默认**（面积 0.87 cm²） |

**结论**: 2D 摩擦稳定域需要 **ω_des=90, ζ=4.0, lissajous θ=0.08×φ=0.8**。
此配方同时把 UR3 从"超调↔调节时间临界"（旧 31.4%/1.03s）拉进全过
（新 20.5%/0.92s，见 §4.5）。更大面积（θ=0.10+）F_cv 顶到 ~10% 边界，
属 GIC 被动极限；更大弧线仍需要力反馈（阶段 2 GAC）。

### 3.5 高阻尼 ζ=2.5 稳定摩擦段，但放大冲击

加大径向阻尼衰减微接触振动，F_cv 从 54%→7.7%；但会放大接触冲击超调 →
**必须配慢逼近速度 0.006 m/s**（默认）。

### 3.6 （阶段 0 遗留，供阶段 2 复用）

- **wrist_3 近零惯量失稳**: URDF 缺腕部电机惯量（~3e-4 kg·m²），任务空间 PD 必失稳
  → 用 MuJoCo 内置 `<position>` actuator（隐式积分）+ 腕部 `dof_armature=0.1`。
- **工具世界 z 速度**: 必须用 `xpos` 有限差分（`data.cvel` 帧约定与世界速度不一致）。
- **Part A 静态扫描**: 须把 position actuator 的 ctrl 置当前位形 q 才零力
  （否则 ctrl=0 施加 kp·(0−q) 的巨大力矩污染接触力）。

## 6. 实验三阶段 2 — GAC 压入（力反馈 + K_env × τ_delay 稳定域）

> **归档**: 2026-08-07。对应计划 A.5（传感器延迟建模）/ A.9（实施顺序步骤 3-4）。
> **脚本**: `se3_control/scripts/verify_gac_contact.py`（单次运行 + 稳定域扫描双模式）。

### 6.1 目的与接线

阶段 1（GIC）验证了**被动**阻抗在刚性接触上的稳定性（无源性，不读力）。阶段 2 走 GAC 的
**完整部署形态**——把力反馈接入控制器，这正是计划 A.4 指出的"位置内环 + 力外环 +
传感器延迟"经典失稳结构本体，是从仿真到实机最大的鸿沟：

```
ee_force 传感器 (世界系) → R_curᵀ → 体坐标系 → τ_delay 延迟线 → GACFilter
→ X_corr 修正期望轨迹 → SE(3) 跟踪
```

与阶段 1（`Fe_raw=None`）相比，阶段 2 的 `GACFilter`（`M_d·dV + D_d·V + K_d·X = F_ext`）
把力传感器读数闭环回位置指令；`τ_delay` 用 `FTDelayLine`（deque 延迟线）建模实机 FT 的
传输/带宽延迟。默认导纳参数: `K_d=[5000,5000,5000,200,200,200]`、`M_d=[10,10,10,1,1,1]`
（临界阻尼 D_d）、内环 ω=90 / ζ=4。工具尖独立刚体（带质量）模拟 FT 传感器前的工具惯量。

### 6.2 结果 1 — 摩擦面积突破（GAC > GIC 被动上限）

单次 GAC 压入（`--theta-amp 0.12`、`solref=[1.0,1.0]`，与阶段 1 同一 §3.1 动态刚度标尺
K_env_dyn≈37 kN/m）:

| 指标 | GAC 阶段 2 | 阈值 |
|---|---|---|
| 摩擦斑块面积 | **1.95 cm²**（GIC 被动上限 0.87 cm²，**2.2×**） | > 0.87 ✓ |
| F 变异系数 | **7.3%**（法向 7.6%） | <10% ✓ |
| 最小压深 / 脱离时长 | 0.2 mm / **0 ms** | 未脱离 ✓ |
| 超调 / make-break | 6.5% / 1 | <30% / =1 ✓ |
| 调节时间 | 1.05 s | <1s ✗（略超） |
| 抬离力归零 / 再误碰 | 418 ms / 0 | 干净 ✓ |
| 力矩 | max 75.2 Nm | 无饱和 ✓ |

**机理**: GAC 力反馈主动调节法向力（`X_corr = Fn/K_d` 修正压深），使切向跟踪在
**更大 rub 幅度**（θ=0.12；GIC 被动在 θ≥0.10 就 F_cv→10%）下仍保持法向力稳定。
GIC 的面积上限是**被动切向阻抗软**所致（§3.4/§3.7），力反馈把这一上限打开。

### 6.3 结果 2 — K_env × τ_delay 稳定域（硬件安全区间）

扫描网格: `solref_tc ∈ [2.0, 1.0, 0.5, 0.3, 0.2, 0.1, 0.05, 0.02]`（§3.1 动态刚度标尺
K_env_dyn 从 **9.7 kN/m 到 11.3 MN/m**，5 个数量级）× `τ_delay ∈ [0, 2, 5, 10, 20 ms]`，
每点 S1 垂直压入 + 保持 3 s，按 A.7 硬门槛分类（稳定 / 极限环 / 发散）。

**结论: 硬件安全区间 = τ_delay ≲ 10 ms，全 K_env 稳定（直至近刚性 11.3 MN/m）；
τ_delay = 20 ms 时全 K_env 极限环。**

| τ_delay | 0 | 2 | 5 | 10 | 20 ms |
|---|---|---|---|---|---|
| 结果（全 K_env 9.7 kN/m → 11.3 MN/m） | 稳定 | 稳定 | 稳定 | 稳定 | **极限环** |

极限环特征（tc=1.0, τ=20ms）: F 峰-峰 52 N（≈158% F_mean）、F_cv=34%、
周期 ≈58 ms（ω≈108 rad/s）、平衡压深被推向近零拐点（0.32 mm）。

> **为何是延迟主导而非 K_env 主导**: 力外环失稳模态 ω_cross = √((K_d+K_env)/M_d)
> = 65–1000 rad/s，远高于导纳滤波器带宽（22 rad/s）。慢滤波器把快速接触振荡平均掉，
> 稳定边界由 **τ_delay 造成的相位裕度消减**决定。实机 FT（UR FT300 ~2 ms、ATI ~1–4 ms）
> 落在安全区内，但延迟必须实测并纳入安全校验。

### 6.4 结果 3 — 摩擦场景的 K_env 失稳边界（从软逐步加硬）

θ=0.12、16 s rub（实际切向速度 12 mm/s），逐步加硬 K_env:

| solref_tc | K_env_dyn | F_cv | 脱离时长 | 判定 |
|---|---|---|---|---|
| 1.0 | 37 kN/m | 7.3% | 0 ms | ✓ 稳定 |
| 0.5 | 82 kN/m | 7.0% | 1 ms | ✓ |
| 0.3 | 184 kN/m | 8.9% | 20 ms | ✓ 边际 |
| 0.2 | 377 kN/m | **10.5%** | 45 ms | ✗ 失稳 |

**摩擦场景失稳边界: K_env_dyn ≈ 184–377 kN/m（tc 介于 0.3–0.2）**。机理:
K_env↑ → 平衡压深 pen_ss = δ_pen·K_d/(K_d+K_env) 收缩（37→184 kN/m 时 0.8→0.2 mm），
逼近 §3.1 的近零压深硬化拐点（solimp width≈0.19 mm 内动态刚度 ~810 kN/m）→
摩擦切向扰动一旦越过拐点，力外环增益 K_env/K_d 爆炸 → 脱离/极限环。

### 6.5 阶段 2 出现的问题及解决方法

**问题 1（摩擦段接触丢失）**: 首次运行摩擦段 F 在 0–89 N 振荡、X_corr 跳到 12.6 mm、
接触周期丢失（ncon=0）、F_cv=113%、脱离 830 ms。
- **根因**: 用 **2 s 缩短 rub** 调试 → 切向速度 98 mm/s，是 16 s 实际速度（12 mm/s）
  的 **8 倍** → 切向滞后"掘进" → 压深越过硬化拐点 → 动态 K_env 瞬时 810 kN/m →
  力外环增益比 K_env/K_d = 160× → 弹跳极限环。方向解耦（K_d_xy=100 kN/m 刚性切向）
  单独也救不回——法向通道才是主导。
- **解决**: 用实际 16 s rub（12 mm/s）→ 稳定（F_cv=7.3%）。**加速测试必须同步降速，
  否则是伪失稳**。

**问题 2（S1 压入扫描全稳定、无边界）**: 0–10 ms 延迟下 K_env 从 0.04 到 11 MN/m 全部稳定。
- **根因**: 静态垂直压入不激发力外环失稳模态（ω_cross 远高于滤波器带宽），慢滤波器
  平均掉快速接触振荡；失稳必须由切向激发或足够长的延迟暴露。
- **解决**: 延迟轴加长到 20 ms → 相位裕度消减 → 全 K_env 极限环（§6.3）；摩擦场景
  （切向激发）→ 暴露 K_env 边界（§6.4）。两者合起来才是完整的稳定域。

**问题 3（近零压深硬化拐点决定安全裕度）**: 同 §3.1，动态接触在 solimp width≈0.19 mm
内刚度 ~810 kN/m（@0.1 mm）vs 0.8 mm 处 ~37 kN/m。**力反馈工作点必须压在拐点右侧
（pen_ss ≳ 0.5 mm）**，否则任意微扰都触发增益爆炸。等价于 δ_pen·K_d/(K_d+K_env) 足够大。
