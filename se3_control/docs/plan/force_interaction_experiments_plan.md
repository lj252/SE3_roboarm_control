## 0. 结论先行: 四个实验加在 GIC 还是 GAC?

**核心结论: 四个实验 GIC 和 GAC 都需要, 但两者测的是不同的东西; 实验基础设施（物理力施加、接触环境、负载变化、分析工具）做成共享一套, 两个脚本各自接入。**

| 实验 | GAC（导纳） | GIC（阻抗） | 各自验证什么 |
|---|---|---|---|
| ① 正弦扫频 | **主测** | 同测 | GAC: 验证导纳滤波器 `1/(M_d s²+D_d s+K_d)` 的**设计带宽/谐振**是否与理论一致; GIC: 辨识**实现出来的阻抗**（自适应惯量成形后的力→位移特性）|
| ② 方向解耦 | **主测** | 基线 | GAC: 体坐标系导纳经 `R_cur` 投影产生的轴间耦合 —— **正好回归刚修完的 Z 振荡问题**; GIC: 操作空间惯量 M̃ 是满 6×6 矩阵, 天然存在耦合, 测其幅值作为基线 |
| ③ 刚性接触 | **主测（硬门槛）** | 同测 | GAC: **导纳 + 刚性环境 = 经典失稳场景**, 是从仿真到实机最大的鸿沟（对应部署计划 H3/M3）; GIC: 被动阻抗理论上更稳, 用接触瞬态验证无源性 |
| ④ 负载突变 | 同测 | 同测 | GAC: 固定 M_d 滤波器的鲁棒性; GIC: **自适应惯量成形**（`K_adapt=ω²M̃`）对动力学突变的鲁棒性 |

理由:
- **扫频**是二者最基本的传递函数表征, 阻抗/导纳控制的标准验收手段都需要;
- **解耦**对 6 自由度几何控制器是固有属性, 两种实现（导纳滤波器 + 几何误差映射）耦合来源不同, 都要量化;
- **接触**是力交互控制的核心卖点/软肋, 两者都不能缺;
- **负载**是鲁棒性普适测试。

实施优先级: **GAC 先行**（已有 ForceProfile + F_ext 通路, 且正是当前工作重心与 Z 振荡回归点）, **GIC 随后**（需先补受力基础设施）。共享库让 GIC 的增量成本最小。

## 1. 现状与差距分析

### 1.1 现有外力机制（GAC）

- `ForceProfile` 类（`verify_gac_mujoco.py:470`）提供 `zero / constant / pulse / spring / tangent` 五种模式;
- 除 tangent 外, 外力**仅作为控制器输入**传入 `controller.compute(..., F_ext=F_ext_ctrl)`（`verify_gac_mujoco.py:916-927`）;
- **关键差距**: 外力从未通过 `data.xfrc_applied` **物理施加**到 MuJoCo 本体。当前是"虚拟注入"——只验证导纳滤波器的数值特性, 不验证真实物理响应（力真的作用在机械臂上）;
- `spring_contact`（`:499`）是**虚拟弹簧**模型, 不是 MuJoCo 真实接触;
- tangent 模式为绕开体坐标系耦合, 直接走惯性系 3-DOF 导纳（`:886-923`）, 与滤波器解耦。

### 1.2 GIC 差距

- `GICController.compute(..., Fe_raw=None)`（`gic_controller.py:60`）保留外力参位但**未使用**——GIC 按设计应是**被动响应**（物理力作用, 控制器不知情, 靠阻抗律自然让位）;
- `verify_gic_mujoco.py` 无任何外力/接触/负载基础设施。

### 1.3 环境差距

两个脚本的 `urdf_joints_to_mujoco_xml` 生成器:
- 机器人 mesh geom 全部 `contype="0" conaffinity="0"`（无碰撞）: GAC `:300`, GIC `:380`;
- 只有 `floor` 平面（`pos="0 0 -0.5"`）: GAC `:311`, GIC `:392`, 末端够不到;
- 无 `force` 传感器、无 `payload` 刚体。

## 2. 共享实验基础设施（核心设计）

> 目的: 把"物理外力 + 传感 + 环境几何 + 分析"做成一套与控制器无关的库, GIC/GAC 各自只负责接线。

### 2.1 双力通路: 物理力 + 感知力

这是整套实验的基础。每个外力实验都要走两条路:

```
物理力 (MuJoCo)                    感知力 (控制器输入)
data.xfrc_applied[ee_body_id]  →   GAC:  F_ext_body = R_curᵀ · F_world   → filter.update()
      (世界系, 作用在末端 body)      GIC:  不传入 (Fe_raw=None, 被动响应)
```

- 末端 body id: `model.site_bodyid[site_id]`（site `end_effector` 已挂在末端链上）;
- **GAC 感知力的坐标变换**: `xfrc_applied` 是世界系, 而 `GACFilter` 期望体坐标系 `F_ext_body`。在脚本里用 `R_cur.T @ F_world[:3]` 模拟**腕部 FT 传感器读数**（力矩同理 `R_cur.T @ T_world[:3]`）;
- 这与真实硬件部署（部署计划 M3: FT 传感器集成）逐层映射一致;
- 现有 `ForceProfile` 五种模式可平滑扩展——`constant`/`pulse` 现在多一条"物理施加"支路, `spring` 被真实接触替代。

### 2.2 接触环境（真实刚性接触, 对应实验③）

在 XML 生成器中新增可碰撞几何（**默认 `contype=1 conaffinity=1`**）:

```xml
<!-- 刚体球: 接触物体 (固定、重质、高摩擦). 半径可配, 默认取较大值 r=0.12,
     便于沿球面做轨迹跟随 (来回摩擦). 接触刚度经 solref 可扫, 见附录 A -->
<geom name="rigid_ball" type="sphere" pos="0.55 0 0.30" size="0.12"
      friction="0.8" condim="3" contype="1" conaffinity="1"/>
<!-- 工具尖: 末端可碰撞小球, 挂在最后连杆 body 下, 半径≈1cm (单点接触, 法向定义清晰) -->
<geom name="tool_tip" type="sphere" size="0.01" pos="0 0 0.1"
      contype="1" conaffinity="1"/>
<!-- 末端 6 维力传感器 (总外力 = 接触力 + xfrc, 全局系) -->
<sensor><force name="ee_force" body="<最后连杆>"/></sensor>
<sensor><torque name="ee_torque" body="<最后连杆>"/></sensor>
```

- 传感器读 `data.sensordata` 即得接触力（全局系）; 备选: `mujoco.mj_contactForce` 逐接触累加（实现时验证坐标变换）;
- 软接触参数（`solref`/`solimp`）默认即可, 必要时调低刚度模拟真实弹性面;
- **刚体球半径、位置做成参数**（`ball_radius` / `ball_pos`, §2.5）, 避免与画圆任务干扰; 完整选型与扫描方法论见**附录 A**。

### 2.3 负载突变（对应实验④）

- 方案 A（推荐）: 在末端 body 下挂一个 `payload` 刚体（`type="box"`, 小质量, `contype=0`）, 实验在 `t = t_step` 时刻修改 `model.body_mass[payload_id]` 与 `model.body_inertia[payload_id]`（需验证 MuJoCo 每步动态都从 model 读取）;
- 方案 B: 直接放大末端连杆自身 `body_mass`（会同时改变原惯性, 需同步缩放 inertia 保持 COM 一致）;
- 物理上等价于"抓取瞬间负载阶跃"。突变幅度: 默认 `×5`~`×10` 原末端质量, 可配。

### 2.4 分析工具库

新增 `core/experiment_analysis.py`, 与控制器无关, 提供:
- `bode_from_steps(freqs, F, resp)` — 逐频稳态幅值/相位 → Bode 图;
- `coupling_matrix(responses)` — 6 输入×6 输出静态增益矩阵, 输出离对角/对角比;
- `contact_metrics(F_contact, t)` — 接触力超调、稳态波动、有无持续振荡;
- `transient_metrics(e, t, t_step)` — 突变后最大偏差、调节时间。

### 2.5 参数集中配置

`config/task_config.py` 新增 `experiments` dict:

```python
experiments = {
    'sweep':    {'axis': 'x', 'amp': 5.0,          # N
                 'freqs': [0.1,0.2,0.5,0.8,1.0,1.5,2.0,3.0,4.0,5.0,8.0],  # Hz 离散扫频
                 'settle_time': 2.0, 'measure_time': 3.0},
    'decouple': {'axes': ['x','y','z'], 'force': 10.0,
                 'torques': ['x','y','z'], 'moment': 1.0},
    'contact':  {'ball_radius': 0.12, 'ball_pos': [0.55, 0, 0.30],  # 刚体球(§2.2, 附录 A)
                 'approach_speed': 0.02,
                 'target_pd': [0.55, 0.0, 0.40]},   # pd 设在球面内侧(球顶 z=0.42) → 主动压入
    'loadstep': {'payload_mass': 0.5, 'step_time': 8.0, 'factor': 8.0},
}
```

## 3. 实验一: 正弦扫频外力（频率响应 / 带宽）

### 3.1 设计

- 任务: **regulation**（固定期望位姿, 外力是唯一激励）;
- 力: 沿单轴（默认 x）`F(t) = A·sin(2πf·t)`, 幅值 `A=5 N`（对 K_d=500 → 稳态位移 ≈ 1 cm, 保证线性区）;
- **离散频率逐点测**（推荐, 避开 chirp 的暂态污染）: 对 `freqs` 中每个频率, 施加 `settle_time` 让系统进入稳态周期, 再记录 `measure_time` 内幅值/相位。逐点测才能拿到干净的相位;
- 扫频范围: GAC 默认滤波参数 M=10, D=100, K=500 → `ω_n=√(K/M)=7.07 rad/s≈1.1 Hz`, `ζ=0.707`。取 `0.1–8 Hz` 即可覆盖谐振与 −3dB 带宽。

### 3.2 接线

- GAC: 物理力 `xfrc` + 感知力 `RᵀF_world` 进 `GACFilter`（测滤波器输出 `X_corr` 与末端位移 `Δp` 两个传递）;
- GIC: 只施加物理力, `Fe_raw=None`; 测末端位移 `Δp`。

### 3.3 分析与指标

| 指标 | 定义 | 参考阈值/预期 |
|---|---|---|
| 幅值比 | `\|Δp(jω)\| / \|F(jω)\|` | GAC 理论 `1/\|K_d − M_d ω² + jD_d ω\|`, DC 增益 `1/K_d = 2 mm/N` |
| 带宽 | 幅值比降到 DC 值 `1/√2` 的频率 | GAC 预期 ≈ 7 rad/s（~1.1 Hz）|
| 谐振峰 | 幅值比最大值 | ζ=0.707 → 无明显峰; 若 ζ 调低可见 |
| 相位滞后 | F 与 Δp 的稳态相位差 | 与二阶系统理论曲线对比 |
| 实测 vs 理论偏差 | 逐频幅值/相位残差 | GAC 应 < 10%（验证滤波器被正确实现）|

产物: Bode 幅值图 + 相位图（每张含 GAC/GIC 两条曲线与理论曲线）。

## 4. 实验二: 方向解耦测试（回归 Z 振荡）

### 4.1 设计

- 任务: **regulation**; 分组施加:
  - 力组: 依次沿 +x / +y / +z 施加恒定力 `F=10 N`;
  - 力矩组: 依次绕 x / y / z 施加恒定力矩 `τ=1 Nm`;
- 每个输入只开一个通道, 等稳态后记录末端 6 维响应 `[Δx, Δy, Δz, Δφ_x, Δφ_y, Δφ_z]` → 得到 **6×6 静态耦合矩阵**（每行归一化）;
- GAC 额外记录 `GACFilter.state['X_corr']`（滤波器输出耦合）与最终末端位移耦合的差异 —— 区分**滤波器耦合**与**跟踪层耦合**。

### 4.2 针对 Z 振荡的回归设计

- 复现场景: 施加 x 向力后, 因体坐标系导纳经 `R_cur` 投影, 力方向相对期望任务系旋转 → 出现 z 向漂移（历史 bug）;
- 断言: 施加 x 向力时 `|Δz|/|Δx| < 5%`（严格）/ `< 10%`（可接受）, 力矩同理;
- 此断言写成 pytest 回归测试, 固化为 CI 项。

### 4.3 指标

| 指标 | 定义 | 阈值 |
|---|---|---|
| 轴间耦合比 | `\|Δy\|/\|Δx\|`, `\|Δz\|/\|Δx\|` 等 | < 5%（GAC 期望）；GIC 记录基线 |
| 平动↔转动耦合 | `\|Δφ\|/\|Δx\|` | GAC < 5%; GIC 记录 |
| 稳态无漂移 | 耦合试验期间有无持续漂移/振荡 | 无 |

产物: 6×6 耦合矩阵热力图（GAC vs GIC 对比）。

## 5. 实验三: 真实刚性接触（接触瞬态稳定性）

### 5.1 设计

- 环境: 加 `rigid_ball` 刚体球（§2.2）; 工具尖加可碰撞 `tool_tip` 球;
- 任务: regulation, `pd` 设在**球面内侧**（如球心 `[0.55,0,0.30]`、半径 0.12 时 `pd=[0.55,0,0.40]`, 沿逼近法向压入球面）→ 控制器主动压入, 形成真实接触;
- 变体（可选）: 先自由空间, 以 `approach_speed` 缓慢逼近再接触, 模拟"接近→接触"瞬态;
- **表面轨迹跟随**（用户补充的核心场景）: 接触稳定后沿球面做弧线往复（来回摩擦）, 最后抬离。详见附录 A §A.6 S6;
- **完整方法论**（参数扫描设计、刚体球/工具选型、传感器延迟建模、评价指标、理想表现）见**附录 A**。

### 5.2 接线

- GAC: 接触力来自 `force` 传感器 → `Rᵀ` 到体坐标 → 进 `GACFilter`（**这是导纳控制真实部署形态: 力传感器回读**）;
- GIC: 不读力, 被动接触（**无源性验证: 撞上去不能发散**）。

### 5.3 分析与指标

| 指标 | 定义 | 阈值 |
|---|---|---|
| 接触力超调 | `(F_peak − F_ss)/F_ss` | < 30% |
| 稳态力波动 | `std(F_ss)` | < 10% F_ss |
| 持续振荡 | 接触后力/位移是否振荡发散 | 无（振荡幅值 < 5% F_ss）|
| 调节时间 | 接触到力进入 ±10% 稳态带 | < 1 s |
| 力矩饱和 | 各关节 `max|τ| ≤ torque_limits` | 不饱和 |
| 稳定性裕度 | 扫环境刚度 `K_env`（solref 缩放）看失稳边界 | 记录边界, 供硬件参考 |

> **为什么这是硬门槛**: 导纳控制 = 位置内环 + 力外环 + 力传感器延迟, 与刚性环境组合是经典失稳结构。MuJoCo 真实接触与虚拟弹簧 `spring_contact` 行为差异大, 这里过的关, 到实物才敢过。对应部署计划 H3（安全）与 M3（FT 集成）。

产物: 接触力/位移时间曲线, `K_env` 稳定域扫描图。

## 6. 实验四: 负载突变（鲁棒性）

### 6.1 设计

- 任务: 可选 **regulation**（看稳态恢复）或 **circle**（看跟踪退化）;
- 在 `t = t_step` 瞬间放大末端负载质量 `×factor`（§2.3 方案 A）;
- 对比: 突变前后轨迹/误差/力矩, 关注突变瞬间的暂态。

### 6.2 分析与指标

| 指标 | 定义 | 阈值 |
|---|---|---|
| 最大瞬时偏差 | 突变后 `max‖e‖` | < 3 cm（regulation）|
| 调节时间 | 回到稳态误差带的 95% | < 2 s |
| 恢复稳态误差 | 突变后 `‖e‖_ss` | 与突变前同量级 |
| 力矩饱和 | 突变瞬间 `max|τ|` | 不饱和 |
| 稳定裕度 | 增大 factor 直到失稳, 记录临界值 | GIC（自适应惯量）应优于 GAC（固定 M_d）|

产物: 突变前后误差/力矩时间曲线; factor 扫描稳定边界。

## 8. 实施路径

### Phase A — 共享基础设施
1. 新建 `core/experiment_analysis.py`（§2.4 分析函数）;
2. 新建 `core/mujoco_env.py`: 从两个脚本抽提并统一 `urdf_joints_to_mujoco_xml`, 新增参数 `contact=True, payload=True, ball_radius=0.12, ball_pos=[0.55,0,0.30]`（一次性重构, 消除两处重复, 与部署计划"Write Once, Run on Any Arm"一致）。**若想最小改动**: 分别在两个脚本的生成器里镜像新增, 不抽共享模块;
3. 新增 `scripts/verify_experiment_mujoco.py`（可选汇总入口）或直接复用 `run_verification`。

### Phase B — GAC 接入（优先级最高）
1. `ForceProfile` 增加 `sine_sweep` / `directional`; `constant` 增加物理施加支路;
2. `run_verification` 增加 `experiment` 参数（`sweep|decouple|contact|loadstep`）;
3. 主循环: `data.xfrc_applied[ee_body_id]` 物理力 + `R_curᵀF_world` 感知力 → `controller.compute`; 接触实验接 `force` 传感器回读;
4. 日志新增 `xfrc`, `F_contact`, `X_corr`, `payload_mass` 通道。

### Phase C — GIC 接入
1. 复用 Phase A/B 的物理力/接触/负载设施;
2. `Fe_raw` 保持 `None`（被动响应）, 仅施加物理力;
3. 同样 `experiment` 参数接线。

### Phase D — 测试与文档
1. 方向解耦断言写成 pytest 回归（固化 Z 振荡修复）;
2. 每组实验存图路径约定 `se3_control/figures/{experiment}/{controller}_*.png`;
3. `usages.md` 增加 `--experiment` 用法与参数表（§8 并入/新增小节）;
4. `config/task_config.py` 增加 `experiments` 段（§2.5）。

## 附录 A: 实验三（刚性接触）方法论细化 — 刚体球设计

> 本节是 §5 的细化与设计变更（2026-08-06）: 接触物体由平面桌面改为**刚体球**（半径可配、默认取较大值），并补充参数扫描方法论、传感器延迟建模、工具惯量、表面轨迹跟随场景，以及理想状态的定性描述。

### A.1 设计原则: 实验 = 参数扫描, 不是单次撞球

实验三的目的不是"让机械臂撞球不坏"，而是**量化"导纳控制 + 刚性环境"这条经典失稳链路的稳定边界在哪里、离边界多远**。因此设计成**参数扫描**，产出**稳定域图**，而非单次撞球。"通过/不通过"的二分结论对硬件转移没有工程价值。

三个独立变量（都要扫）:

| 变量 | 物理含义 | 建议范围 |
|---|---|---|
| 环境刚度 K_env | 刚体球接触刚度（solref 时间常数控制） | 默认 ~0.02（软）→ ~1e-4（近刚性） |
| 接触速度 v_approach | 冲击能量 | 0.01 → 0.2 m/s 分档 |
| 传感器延迟/带宽 τ_bw | FT 回读滞后 | 0（理想）→ 数倍控制周期 |

**方法论要点: 先扫 K_env 找稳定域, 回到稳定域内再测性能指标。** 稳定性与性能分开判——先判"发不发散、有没有极限环"（一票否决），再判"超调、调节时间"。

### A.2 接触物体: 刚体球选型

用**刚体球**作为接触物体（替代平面桌面）:

- **固定、重质**: 环境位移必须≈0，否则测的是"臂撞移动物体"的耦合动力学而非控制器稳定性；质量要远大于臂;
- **半径可配, 默认取较大值**（如 r=0.12 m）: 半径大 → 表面曲率小 → 便于沿球面做轨迹跟随（来回摩擦），球面不同区域的法向变化平缓;
- **高摩擦**（μ≈0.8~1.0, `condim=3`）: 固定接触; 低摩擦变体看滑移;
- **接触刚度可扫**: MuJoCo 接触是有限刚度约束，不存在数学上无穷硬的墙。接触刚度经 `solref`/`solimp` 控制——**失稳临界刚度值本身就是最值钱的实验数据**;
- 半径、位置做成参数（`ball_radius` / `ball_pos`, §2.5），避免与画圆任务干扰。

### A.3 工具层: 带惯量的球尖

- 工具尖 `tool_tip` 球（半径≈1cm）: 单点接触、法向定义清晰，主场景首选; 平端面 = 面接触，留到后续;
- **传感器与接触点之间要有工具质量**: 真实系统 FT 装在腕部，法兰/探针/夹具的质量惯量在传感器前方——这是力控制经典失稳源之一（工具惯量与环境的互耦）。仿真里把接触点直接挂在无质量连杆上会测得过于乐观。建议把工具尖做成独立小刚体 body（几十克~百克级），传感器读数取它到腕部的约束力。

### A.4 控制机械臂的方式

- **GAC（导纳, 主测）**: 走完整部署形态——接触力→传感器→Rᵀ 到体坐标→进 `GACFilter`→位置修正。这就是"位置内环 + 力外环"失稳结构本体;
- **GIC（阻抗, 被动基线）**: 不读力（`Fe_raw=None`），撞上去靠阻抗律自然让位，验证无源性。

期望设定:

- **位置压入式**（S1 先用）: `pd` 设在球面内侧（沿逼近法向压入）。稳态接触力由 K_d 与压入深度的关系决定（导纳弹簧 F_ss ≈ K_d·penetration）。**K_d 就是"接触手感多硬"的旋钮**——实验要量化"手感（K_d）vs 稳定性（K_env 边界）"的权衡曲线;
- **力跟踪式**（加分项）: 设 F_des，比例/积分力误差驱动，更接近实机力控。建议 S1 稳定后再上;
- 控制器本体不用改（`gac_controller` / `gic_controller` 不动）; 要改的是环境（可碰撞几何、传感器、延迟模型）和实验主循环接线。

### A.5 传感器延迟建模（仿真→实机转移的关键）

当前 GAC 感知力是 `R_curᵀ F_world`——**零延迟、完美测量**。对扫频/解耦这是可接受的理想化，但对接触稳定性是**系统性乐观**: 实机 FT 有传输延迟和带宽，失稳边界随延迟急剧收缩。建议:

- 给感知力加低通（模拟 FT 带宽 ~1kHz）或整数倍控制周期的传输延迟;
- 延迟作为 K_env 扫描的**第二个扫描轴**，输出稳定域图: 横轴 K_env、纵轴 τ_delay、颜色 = 稳定/极限环/发散。

这张图才是给硬件的"安全操作区间"。**没有它，仿真"过了接触关"，实机大概率翻车**——这正是 §5 把它定为硬门槛的原因。

### A.6 场景矩阵（按优先级）

| 场景 | 内容 | 测什么 |
|---|---|---|
| S1 垂直压入（主场景） | 沿球面法向匀速逼近 + 压入保持 | 接触建立质量、稳态力 |
| S2 冲击扫描 | 变体 S1，只扫 v_approach（0.01→0.2 m/s） | F_peak vs v（应近似线性） |
| S3 斜向接触 | 法线成角逼近 | 切向力 + 摩擦滑移 |
| S4 刚度扫描（关键产物） | 固定 v，扫 K_env | 稳定域边界 |
| S5 接触中扰动 | 保持接触后注入 xfrc 阶跃 | 瞬态抑制（抗扰动） |
| **S6 表面轨迹跟随（用户核心场景）** | 接触稳定后沿球面做弧线往复（来回摩擦），最后抬离 | 表面跟随误差、接触力保持、是否脱离、离开瞬态 |

### A.7 评价指标

**先判稳定性（硬门槛, 一票否决）**:

| 指标 | 判据 |
|---|---|
| 发散 | 接触后力/位移振幅单调增长 → FAIL |
| 极限环 | 接触后力/位移是否持续等幅振荡（幅值 > 5% F_ss）→ FAIL |
| 回跳 | 首次接触后 make-break 循环次数，理想 = 1 次 |
| 力矩饱和 | max\|τ\| 顶到 torque_limits → FAIL |

**再判性能（稳定域内才有意义）**:

| 指标 | 定义 | 阈值 |
|---|---|---|
| 接触力超调 | (F_peak − F_ss)/F_ss | < 30% |
| 稳态力波动 | std(F_ss) | < 10% F_ss |
| 持续振荡 | 接触后力/位移振荡幅值 | < 5% F_ss |
| 调节时间 | 接触到力进入 ±10% 稳态带 | < 1 s |
| 力矩饱和 | max\|τ\| ≤ torque_limits | 不饱和 |
| 力跟踪误差 | \|F_ss − F_des\|/F_des（力跟踪模式） | 记录 |
| 穿透量 | F_ss/K_d | 越小手感越硬 |
| 能量/无源性（GIC 专属） | 接触后控制器做功 ∫τ·q̇ dt 应为非增 | 非增 |

**关键产物**:

1. 接触力/位移/关节力矩时间曲线（4 相标注: 逼近/接触/保持/离开）;
2. **稳定域图**: K_env × τ_delay（或 × v_approach）→ 稳定/极限环/发散色块图;
3. 力-位移**相图**（判极限环最直观: 收敛到一点=稳定, 闭合圈=极限环）;
4. 能量曲线（GIC 无源性证据）。

### A.8 理想表现

**定性描述（用户提出）**: 在 GAC 或 GIC 控制下的机械臂，应该**按照给定的路径逐渐逼近刚体**; 在**接触到刚体的时候反弹小、并且稳定**; 能够**按照刚体球的表面运行轨迹**（例如在球的表面来回摩擦）; 最后**离开球的表面也比较稳定顺利**。

**定量落点**（把上面的描述翻译成可测指标）:

| 阶段 | 理想行为 |
|---|---|
| 逼近 | 沿给定路径匀速/按规划逐渐逼近，无提前抖动 |
| 接触建立 | 接触力平滑建立、**单次接触不回跳**（反弹小）、超调 <30% |
| 保持/表面运行 | ~0.5–1s 落入 ±10% 稳态带; 沿球面轨迹跟随误差小、接触力波动 <10%、**不脱离球面**、无极限环、力矩不饱和 |
| 离开 | 抬离干净、无振铃、无再次误碰（make-break = 1） |

**一句话概括**: 接触像手指按在球面上——建立干净、稳定、无振铃; 刚度越高越能保持稳定（GAC 到某个边界，GIC 到近乎无穷）; 表面往复摩擦不掉球、抬离不带起振。

### A.9 实施顺序

1. **阶段 0 接触模型标定**（不接控制器）: 纯运动学压入，标定 MuJoCo 接触的 K_env 真实值与回跳特性——没有这步，所有控制器结果都被接触求解器行为污染;
2. **GIC 被动接触先做**: 环境基础设施最简单、被动性验证最容易过，先把"环境 + 传感器 + 分析库"跑通;
3. **GAC 压入**: 从软 K_env 起步逐步加硬，找失稳边界;
4. **加延迟建模**，重扫稳定域，出硬件安全区间;
5. 写回归断言（固化稳定域内参考点必须稳定，或把稳定域边界值存进回归）。

### A.10 阶段 0 结果（2026-08-06，脚本 `se3_control/scripts/verify_contact_calibration.py`）

**Part A — 静态 K_env 标定**（直接 qpos + `mj_forward`，零速度，力 = K_env·pen + 重力支撑预载）:

| 机器人 | K_env (默认 solref) | 预载 (重力支撑) | R² |
|---|---|---|---|
| UR12e | 17.84 kN/m | 61.6 N | 0.9998 |
| UR3 | 8.06 kN/m | 23.1 N | 1.0000 |

环境刚度扫描（`geom_solref` 时间常数 tc↓ → 变硬）: UR12e `tc=0.02→17.8, 0.01→31.7, 0.005→45.6, 0.002→58.9 kN/m`；UR3 相应 8.1→26.8。MuJoCo 无真正刚墙，`solref` 即"环境刚度标尺"，是实验三参数扫描的 `K_env` 维度。

**Part B — 动态冲击回跳**（position actuator 恒速压入，实测 UR12e）:

| v指令 (m/s) | v_impact 实测 | F_peak (N) | F_ss (N) | 超调% | 断开 | e | settle (s) |
|---|---|---|---|---|---|---|---|
| 0.05 | 0.139 | 104 | 103 | 1.8 | 0 | 0.09 | 0.18 |
| 0.10 | 0.175 | 107 | 103 | 4.2 | 0 | 0.10 | 0.06 |
| 0.20 | 0.238 | 167 | 103 | 61.9 | 0 | 0.10 | 0.04 |

**关键结论**:
- **F_peak 随冲击速度单调放大**（104→167 N），超调 1.8%→62% —— 这正是"接触建立反弹大小"的量化维度;
- **恢复系数 e≈0.09–0.10**（高刚度伺服 + solref 临界阻尼吸收了反弹），**无 make-break 跳离**（断开=0）;
- **F_ss≈103 N 恒定**（三段一致的保持稳态力）;
- 冲击越猛 settle 越快（0.18→0.04s），因为高冲击力快速进入稳态带。

**实现要点**（对后续实验三有直接价值）:
- 任务空间 PD 在近零惯量 `wrist_3`（URDF 缺腕部电机惯量，~3e-4 kg·m²）上**必然失稳**；改用 **MuJoCo 内置 `<position>` actuator**（隐式积分）+ 腕部 `dof_armature=0.1` 电机转子惯量 → 稳定;
- 每机器人默认增益：UR12e `kp=[5000,5000,3000,400,250,150]`，UR3 `kp=[3000,3000,1800,200,150,80]`（UR3 小一个量级，UR12e 增益会塌缩）;
- 工具世界 z 速度必须用 **xpos 有限差分**（`data.cvel` 帧约定与世界速度不一致，实测逼近时 cvel[tip,2]≈0 而有限差分=−v_app）;
- Part A 静态扫描须把 position actuator 的 **ctrl 置当前位形 q** 才零力（否则 ctrl=0 会施加 kp·(0−q) 拉向 q=0 的巨大力矩，污染接触力）;
- 动态接触力含 solref 阻尼项 B·peṅ（damping=1 临界阻尼），故冲击 F_peak ≫ 同压深静态力，两者分开解读。

### A.11 阶段 1 结果 — GIC 被动接触全流程（2026-08-06，脚本 `se3_control/scripts/verify_gic_contact.py`）

**场景**: 逼近(匀速)→ 接触保持 → 表面弧线往复摩擦(2 往返) → 抬离 → 保持。GIC 被动（`Fe_raw=None`，控制器不读力），`<motor>` 力矩驱动，腕部 `dof_armature=0.1`。

**标定后默认参数**（`python se3_control/scripts/verify_gic_contact.py --no-viewer` 直接复现）:

| 参数 | 值 | 说明 |
|---|---|---|
| 接触 solref | `[1.0, 1.0]` | 动态接触刚度 ≈ 36 kN/m（见下方关键发现） |
| 表面/工具摩擦 | 0.15 / 0.15 | 有效 μ = sqrt(0.15·0.15)=0.15 |
| δ_pen | 8 mm | 阻抗力指令（实际平衡压深 0.8mm） |
| 逼近速度 | 0.006 m/s | 慢 → 冲击超调 <30% |
| ω_des / ζ | 40 rad/s / 2.5 | 摩擦段径向振动衰减 |
| θ_amp | ±0.08 rad (±4.6°) | GIC 被动稳定摩擦上限 |

**指标对照 A.8 理想状态（全 ✓）**:

| 阶段 | 指标 | 结果 |
|---|---|---|
| 逼近 | 自由空间最大轨迹误差 | **1.0 mm** |
| 接触建立 | 超调 (F_peak−F_ss)/F_ss | **26.4%** (<30% ✓) |
| 接触建立 | make-break | **1**（单次建立不回跳 ✓） |
| 接触建立 | 调节时间 | **0.82 s** (<1s ✓) |
| 表面摩擦 | F 变异系数 | **7.7%** (<10% ✓) |
| 表面摩擦 | 最小力 / 最小压深 | **25.5 N / 0.7 mm**（未脱离 ✓） |
| 表面摩擦 | 脱离时长 / 极限环 | **0 ms / 无** ✓ |
| 离开 | 力归零 / 再误碰 | **406 ms / 0 次** ✓ |
| 全程 | 力矩 | max 41.7 Nm（无饱和 ✓） |

**关键发现（对 GAC 阶段 2 同样重要）**:

1. **`mj_forward` 静态力 ≠ `mj_step` 动态力**。默认 solref `[0.02,1]` 时：静态（去重力）接触 F≈19 kN/m·pen（≈ Phase 0 标定）；但动态接触在近零压深处等效刚度 **~6 MN/m**（约束解算器的隐式硬化）。GIC 阻抗刚度 K_rad=ω²·M̃（bw40 ≈ 9 kN/m）远小于该刚度 → 尖端只能压入 ~5 µm，力对径向微扰超敏感 → F 振荡 0–57 N、频繁脱离。**必须把 solref 时间常数调大到 `[1.0,1.0]`，动态接触刚度降到 ~36 kN/m**，GIC 才能在 mm 量级压深上稳定控力。
2. **A.10 Part A 的 63 N 预载是重力支撑，不是接触刚度**。静态扫描强制 qpos 压入、无重力补偿，接触力含整臂重力支撑项（61.6 N）；动态 GIC 有 bias 重力补偿，无此项。两者解读需分开。
3. **摩擦组合 = 几何平均**：MuJoCo 两 geom 有效 μ = sqrt(μ₁·μ₂)。工具尖默认 1.0 会破坏单设球摩擦的效果，必须同时调低两者（工具尖已支持 `friction` 属性）。
4. **GIC 被动稳定摩擦有幅值上限**（θ_amp ≈ ±0.08 rad）：切向阻抗刚度软（K_tan≈1 kN/m）叠加摩擦拖拽（~4 N / 960 N·m⁻¹ ≈ 4.6 mm ≈ 2–3° 相位滞后），幅值加大 → 切向加速度超驱动力 → F 振荡、脱离。更大弧线往复需要力反馈（阶段 2 GAC）。
5. **高阻尼 ζ=2.5 稳定摩擦段**：加大径向阻尼衰减微接触振动，F_cv 从 54%→7.7%；但会放大冲击超调，需配合更慢逼近速度。

**UR3 变体**（`--robot ur3`）: 摩擦段全过（F_cv 6.4%、不脱离、离开干净），但接触建立处于临界——默认逼近速度 0.006 时超调 31.4%（>30%），0.005 时超调 25.7% 但调节时间 1.03s（>1s）。UR3 惯性轻、接触力建立慢，超调↔调节时间两者不可兼得，属 UR3 固有折衷; UR12e 为演示主机器人全指标通过。

**回归断言建议**（固化稳定域参考点）: 默认参数下（UR12e）`F_cv<10%`、`F_min>F_off`、`overshoot<30%`、`breaks==1`、`力归零<1s`。
